Bookmarklet loader probe PROTOTYPE

Hosted at . The probe script is probe.js, the probe page is probe.html.

1. Bootstrap runner (tiny, use this first)

A short bookmarklet that loads runner.js from this host with a script tag (fallback: fetch + eval) and then runs every method below. Open an aruodas.lt advert, tap the bookmark, wait ~2 minutes. A panel appears with the report and Copy / Download / Share buttons. If nothing happens within ~10 s and no alert shows, script loading is blocked; fall back to the all-in-one runner.

Same report, but every method is inlined so it works even when nothing can be loaded. Also a useful test of how long a bookmark Chrome accepts: if the report panel never appears, the bookmark was truncated.

2. Minimal single-method bookmarklets

Each one loads probe.js with exactly one technique and shows a green toast when the probe runs (or an alert on failure). These are what the final bookmarklet would look like. Length shown is the raw javascript: URL length.

3. How to read the report

  • ok: probe.js executed and called back into the page. Candidate.
  • fail: an error event or exception, message included.
  • timeout: nothing happened within 8 s (silent CSP block, popup blocked, ...).
  • skipped: precondition missing on that page (e.g. no nonce to reuse).
  • CSP violations captured via securitypolicyviolation are listed separately.
